# Urban Routes: Requirements Analysis & Test Design (Carsharing)

## 📝 Project Description
This project focuses on the deep logical decomposition and test design for the newly integrated **Carsharing** feature within the Urban Routes platform. The analysis involved translating complex corporate business rules and dynamic pricing requirements into concrete, structured QA artifacts.

## 🛠️ Technologies & Tools Used
* **Analysis Techniques:** Logical Decomposition, Logic Flowcharts
* **Test Design:** Equivalence Classes, Boundary Value Analysis (BVA)
* **Documentation:** Markdown, GitHub

## 📋 Key Deliverables Included
* Complete test suites covering booking and billing matrices.
* Edge-case scenario mappings for dynamic fare calculation.
* Traceability matrices from business requirements to functional test scenarios.
